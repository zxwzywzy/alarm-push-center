# 本地优化与验证

2026-10-13：本次代码优化无需连接路由器。

## 已调整

- OpenWrt 服务：配置保存、启动、停止、重启及钉钉群会话自动保存共用同一把锁，避免并发操作交错；启动失败时释放采集资源，关闭失败时仍执行宿主关闭流程。
- Windows / OpenWrt 共享历史：按文件长度和修改时间缓存解析与排序结果；本程序写入、删除或外部文件变化后刷新缓存。最近记录按记录时间排序。
- 历史清理：按设备删除与文件裁剪采用同目录临时文件原子替换；清空历史同时覆盖已改名、已删除设备的旧记录和损坏行。
- 网页接口：API 响应禁止缓存，未知 API 返回 JSON 404；网页请求 20 秒超时并给出中文提示，避免轮询一直挂起。
- 请求错误：网络不可达、超时及无效响应分别给出中文提示；未知 API 的 GET、POST、PUT、DELETE 均返回 JSON 404，避免返回网页被误当成配置。
- 编辑体验：中文搜索输入法组合期间不重绘，搜索后保留光标位置；登录过期后重新登录保留当前页面内的未保存草稿。主动退出仍会提示是否放弃修改，刷新或关闭页面仍需先保存。

## 一键验证

在 Windows 上安装 .NET 10 SDK 和 Node.js 后，在项目根目录执行：

```powershell
& .\验证本地代码.ps1
```

脚本编译 Windows 与 OpenWrt 项目，检查前端语法，运行前端、API 与 Windows 离线自检。任何一步失败都会停止并返回错误。

API 测试启动监听 `127.0.0.1:5098` 的临时服务，使用临时配置、密码和模拟采集源；验证草稿测试、配置校验、12 次并发保存、启停重启、历史清理、密码修改与会话失效，结束后清理临时服务和文件。运行前请确保该端口没有被占用。

2026-10-13 本机验证结果：Windows 客户端、OpenWrt 服务及 TIA 导出工具均编译成功，零警告、零错误；11 项网页/API 测试通过，116 条离线自检断言通过。网页流程测试直接执行实际页面函数，验证错误响应处理及重新登录时的草稿保留；中文输入法体验仍需浏览器交互验收。
