# 运行总览趋势

Windows 客户端 1.3.0 与 OpenWrt 网页版 1.6.0 使用同一套统计逻辑。下文早期版本的验证记录按当时版本保留；当前下载入口见 [项目首页](../README.md)。

## 曲线与指标

- 报警趋势：每个采样周期新增报警与恢复事件；按启用规则的实际触发计数，冷却抑制的消息不重复计数。同一报警匹配多条规则时，各规则分别计数。
- 连接趋势：成功连接设备数量，使用右侧独立坐标轴。离线设备的旧报警值不计入当前激活报警。
- 采集趋势：平均读取周期耗时（包括连接建立与 PLC 访问锁等待）、每秒读取次数和采集成功率。失败读取也纳入耗时和成功率统计；因主动停止而取消的读取不计作失败。
- 资源趋势：程序 CPU 使用率，按可用逻辑处理器数归一化；程序内存为实际工作集 MB。这些不是路由器整机 CPU 或整机内存数据。
- 推送指标：待发送队列长度、最近采样周期最终投递失败数量；达到重试上限或队列无法入队均计作投递失败。

## 采样与保留

每 5 秒采样一次，时间范围可选最近 5 分钟、15 分钟或 1 小时。当前指标也是最近一次采样值，可能比设备实时心跳最多晚一个采样周期。

趋势在内存中最多保留 721 个采样点，页面刷新和切换时间范围不会清空；网页关闭期间后台仍采样。停止采集时读取数、连接数归零，程序资源继续采样。重启采集不会丢失已有曲线，累计计数换代不会产生负数或虚假的跳变；退出程序/重启网页服务后曲线清空。

数据不足两个采样点时显示等待提示，不补造历史数据。网页 SVG 曲线点可悬停查看时间和值，且提供无障碍文字说明。客户端使用本地绘图控件，无需外部图表服务。

## 验证

13 项网页/API 测试、120 条 Windows 和共享核心离线检查、22 条邮箱找回检查通过。新增检查覆盖真实读取成功/失败计数、采集耗时、进程资源、重复采样保护、后台采样接口，以及不等间隔时间轴和不同单位的双坐标轴。

网页和 Windows 截图均通过隔离的模拟采集源实际运行生成，不是生产 PLC 数据。真实 PLC 与 OpenWrt ARM64 运行还需现场验证。

安装包在 `dist/OpenWrt-1.3.1` 与 `dist/Windows-1.1.0` 分别整理。本轮未部署到路由器，内网穿透仍暂停。
