# 常见问题与排查顺序

[返回手册](README.md)

## 网页打不开 / 登录不了

1. 先从局域网访问 `http://路由器IP:5080`，再检查公网域名，区分插件故障与隧道故障。
2. LuCI 查看插件是否启动。关闭“开机启动”后，重启路由器不会自动打开插件。
3. SSH 查看 `/etc/init.d/alarm-push-center status` 与 `logread -e alarm-push-center`。
4. 报警密码、root 密码和 UFI-TOOLS 口令互不相同。先使用正确入口对应的密码。
5. 邮箱找回需事先配置 STARTTLS SMTP；通常 587，**不支持 465 隐式 TLS**。验证码 10 分钟有效，发送请求至少间隔 1 分钟，其他限制以页面提示为准。
6. 更新后界面仍旧：重新登录并强制刷新缓存；检查后端显示版本，确认安装的是对应新包。

## OPC UA 一直离线

1. 先看主采集是否启动、设备是否启用；记录完整错误。
2. 检查 endpoint 是否指向正确设备。路由器上的 `127.0.0.1` 不代表电脑；端口通常为 4840，但以实际服务器为准。
3. 在实际采集端检查到 PLC 的网络路由、端口、防火墙；ping 通只证明 ICMP，不能证明 OPC UA 端口可达。
4. 电脑仿真 PLC 时，核对 PLCSIM Advanced 的外部 TCP/IP 适配器与有线网卡的虚拟交换机设置，允许来自路由器的连接。
5. 网络连通后再核对匿名/用户登录、服务器信任和节点访问权限；不要为了连接测试直接关闭整台 PLC 的所有安全设置。
6. 数组模式检查数量/数组两个 NodeId 与质量；ProDiag 检查 A&C、ProcessDiagnostics 事件节点和实际报警触发。
7. 老 OpenWrt 包出现 RC2 / `digital envelope routines::unsupported`，核对 `libopenssl-legacy` 依赖是否成功安装；新包声明该依赖。

## 有读数但不报警 / 报警文本不对

- 规则是否启用并关联当前设备？匹配码和字段是否过严？事件是否被冷却抑制？
- 数组有效数量是否为 0，编号是否落在 `0..N-1` 外，是否被设为无效编号？
- 字典是否导入到这台设备当前规则，并保存/应用？
- ProDiag 使用完整 AlarmId、实例、FB、文本列表与索引核对。不要按两张表的视觉行顺序硬配。
- 导入前原 CSV 是否已有乱码？Excel 是否保存成 UTF-8？占位符是否缺少关联值？见[报警文本](ALARMS.md)。

## 钉钉“用户不存在” / 没有卡片

- 企业应用必须填成对的 Client ID/Secret；个人填企业 userId，不是手机号或 unionId，接收人要在应用可见范围。
- 群填 openConversationId，机器人必须加入；需要自动记录时保存、启动接收命令后在目标群 @机器人发 `/status`。
- 卡片需已发布模板、正确模板 ID、相关权限和 Stream 处理。
- 只有指令回复有卡片：开启“报警推送显示操作按钮”，保存/应用并触发新报警；历史旧消息不会自动变成卡片。
- 测试消息成功但正式报警不发：检查启用发送、正式保存配置、设备规则和日志，不要只看渠道测试。

## PLC 按钮不能写

检查管理员、允许 PLC 写入、动作启用、目标设备、地址/NodeId、数据类型和服务器写权限。S7 使用绝对地址需非优化 DB；Modbus 需可写表；OPC UA 节点需可写。确认按钮 60 秒过期后应重新发起，重复点击不会再次执行。脉冲需配置恢复值并验证现场反馈。

## 随身 WiFi 口令对但认证失败

使用原始 UFI-TOOLS 登录口令，不是其他后台密码，不要自行散列。升级到当前版本再检测。核对地址为 `http://私有IPv4:2333`（不是 `::2333`）、AT 槽位、SIM 和连接路径。检测成功不等于呼叫成功，真实测试需要对端确认响铃。[电话流程](PHONE.md)。

## 手机扫码后连不上

- 生成码时填的地址是否从手机可达？相机扫描成功与网络连接成功是两件事。
- 二维码是否已过 2 分钟或已被用过？重新生成。
- 授权是否撤销、过 30 天或因修改管理密码失效？重新授权。
- iPhone 明文地址是否被系统策略拦截？优先 HTTPS。
- 域名在浏览器打不开时，先修复域名/隧道，再重试 App。App 不会自动配置路由器公网访问。

## 发布包、源码与数据

安装从 Releases 下载对应平台包，源码 ZIP 需要开发环境编译。清理 `bin`、`obj`、`node_modules` 等后可重新构建，但不能删除长期签名密钥、现场配置和历史备份。报告问题时提供版本、平台、脱敏错误、操作步骤与一条示例，勿公开 token、完整配置或密码。
