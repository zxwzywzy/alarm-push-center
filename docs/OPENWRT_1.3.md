# OpenWrt 1.3：设备工作区与手动运行

这是 1.3 的历史开发记录。当前版本为 1.5.1，已发布安装包，单设备保存和电话提醒等行为见 [当前安装与配置指南](releases/openwrt-1.5.1.md)。下文关于“本地开发版”和保存范围的描述仅对应当时的版本。

## 界面

每次选择一台设备，统一管理它的“连接与采集”“报警规则与文本”“设备历史”。规则列表仅显示当前设备的规则；新增规则自动关联当前设备。切换设备保留页面内的编辑草稿，保存仍会应用完整配置。

通知通道及机器人仍在“通知与交互”统一管理。已有通知目标和机器人按钮配置保留。

采用深蓝导航、蓝色操作按钮与设备上下文标题；切换页面提供轻量过渡，尊重系统减少动态效果偏好。手机宽度采用单列布局。

## 两层运行控制

1. OpenWrt“服务 → 报警推送中心”：启动/停止插件、选择插件开机启动。停止插件后网页服务也会停止，需通过 LuCI 重新启动。
2. 网页“系统设置”：开启/停止当前采集、选择网页服务启动后是否自动采集。

首次安装默认不启用插件开机启动、不自动开始采集。升级保留原来的插件开机启动偏好；可在 LuCI 中关闭。新增的自动采集偏好默认关闭。

保存配置只会重新加载正在运行的采集；采集已停止时仍保持停止。明确点击“启动”或“重启”会开始采集。

## 邮箱找回

先登录配置台，在“系统设置 → 启动偏好与邮箱找回”填写找回邮箱、SMTP 地址、端口、发件人、用户名和邮箱授权码，并启用邮箱找回。保存时需再次输入当前管理密码。

支持 STARTTLS SMTP（通常端口 587）；不支持端口 465 的隐式 TLS。SMTP 授权码留空保留原值，接口不会返回已保存的授权码。设置文件在路由器上仅允许文件所有者读写。

忘记密码后，登录页点击“通过邮箱找回”，发送验证码，填写邮箱中收到的验证码和两次新密码。验证码 10 分钟有效，单次使用；最多尝试 5 次错误验证码，发送间隔至少 60 秒。修改密码、更新找回设置后，旧验证码失效。重置密码会注销所有配置台会话。

需要先配置有效邮箱服务，并确保路由器可以访问 SMTP。尚未绑定邮箱时可通过 OpenWrt 后台读取 `/etc/alarm-push-center/web-password`；配置台密码和路由器 root 密码是两个独立密码。

## 本地验收

11 项网页/API 测试、116 条共享核心离线自检及 22 条邮箱找回检查通过。浏览器实际检查了两台模拟设备规则隔离、采集开关和手机布局。

邮箱测试使用隔离的邮件发送器验证完整验证码请求/重置流程，不发送真实邮件。SMTP 实际投递、ARM64 安装、LuCI 的 rpcd 启停权限与真实设备连接，需现场验收。

本轮只修改本地代码及生成安装包，内网穿透与路由器部署待后续继续。
