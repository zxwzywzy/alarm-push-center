# OpenWrt 网页控制台

当前版本 **1.7.0**，适配独立浏览器、LuCI 内嵌页面和手机。[下载安装与升级](INSTALLATION.md) · [电话提醒详细说明](电话提醒与设备工作区.md)。

## 日常操作

- 运行总览显示真实在线率、连接时长、最近成功采集心跳和离线原因。点设备可以进入对应配置。
- “设备工作区”每次选择一台设备，下方分别显示“连接与采集”“报警规则与文本”“电话提醒”“设备历史”。规则和文本只属于当前设备。
- “一键检查此设备”使用当前草稿，逐项检查配置、规则和连接；开启电话提醒时也检查网关。它不会保存、发送消息或拨打电话，结果会在修改参数后清除。
- “保存此设备”只提交当前设备和所属规则；其他设备和通知通道的草稿保留。该操作仍会重新加载正在运行的采集，电话计时重新开始。
- 设备表单突出地址与节点，认证和采集调优放在可展开区域。切换协议会填入对应默认参数。“测试连接”使用当前草稿，不保存、不发送报警。
- 报警文本库每页 50 条，搜索覆盖完整字典，支持报警码、实例名、文本、FB 编号与文本列表引用。可全选本页或全部匹配结果，跨页勾选会保留。
- CSV / TSV 支持 UTF-8、带 BOM 文件、带引号的逗号及多行文本。支持报警字典与 PLC 报警文本列表，保留 FB 编号、文本列表名称和索引。GBK 文件需先转换为 UTF-8。
- 通知和交互在同一页面分为两个页签；PLC 写入动作会显示设备、节点、类型、地址、值与脉冲的配置表单，仍遵循现有机器人确认流程。
- 顶栏显示修改是否已保存。顶栏“保存并应用”及 Ctrl+S 提交全部页面的草稿；有未保存修改时退出或关闭页面会提醒。保存期间继续输入的内容会保留为新草稿。
- 历史报警仍按设备查询最近 20 条，每页 10 条；清除前显示具体设备并要求确认。

## 电话提醒

在“系统设置 → 随身 WiFi 电话网关”填写 UFI-TOOLS 地址、原始登录口令和 AT 槽位，保存后检测连接。在“设备工作区 → 电话提醒”按设备启用、填写报警持续秒数与号码。只有连接了支持拨号的随身 WiFi、SIM 就绪且网关空闲时才可能呼叫。

1.5.1 修复正确口令也会被拒绝的问题。直接输入原始口令，插件自动完成认证转换；无需填写设备后台登录密码，也不要手工计算口令散列。需要真实测试时使用“拨打一通测试电话”并核对号码后确认。

报警恢复、采集断线或停止时取消计时。每条持续报警只尝试一次拨号，多条报警共用最短呼叫间隔。当前支持拨号提醒，暂无语音播报。

## 运行与密码

LuCI“启动/停止插件”控制网页服务，停止后需从 LuCI 再启动。“开机启动插件”决定路由器重启后是否启动网页服务。配置台“系统设置”单独控制采集及其启动偏好。

管理密码独立于 OpenWrt root 密码和 UFI-TOOLS 登录口令。“系统设置”支持修改管理密码和配置邮箱找回；邮箱找回需预先填写有效 SMTP 服务，详见 [密码与邮箱找回](releases/openwrt-1.5.1.md#密码与邮箱找回)。

## 时区

插件通过启动脚本读取 OpenWrt 系统的时区名称并为 .NET 设置 `TZ`。软件包增加 `zoneinfo-asia` 依赖，支持亚洲时区，避免只有 `/etc/TZ` 时程序回退到 UTC、报警消息相差 8 小时。其他地区需另装对应的 `zoneinfo-*` 软件包。

## 开发验证

```powershell
dotnet build AlarmPushCenter.OpenWrt -c Release
node --test AlarmPushCenter.OpenWrt/tests/*.test.cjs
dotnet run --project AlarmPushCenter.OpenWrt/tests/phone/PhoneChecks.csproj -c Release
dotnet run --project AlarmPushCenter.OpenWrt/tests/security/SecurityChecks.csproj -c Release
```

接口检查使用独立临时配置和模拟设备，不连接现场 PLC 或发送外部通知。另需使用浏览器验证桌面、手机和 LuCI 内嵌布局。
